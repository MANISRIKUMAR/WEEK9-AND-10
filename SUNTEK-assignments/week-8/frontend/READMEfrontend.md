# Frontend Application

A modern frontend application built using React, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- React 19
- Vite
- Tailwind CSS
- React Router
- React Hook Form
- ESLint

---

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
```

Move into the project folder:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run Development Server

```bash
npm run dev
```

The app will start on:

```bash
http://localhost:5173
```

---

## 🏗️ Build for Production

```bash
npm run build
```

---

## 👀 Preview Production Build

```bash
npm run preview
```

---

## 🧹 Run ESLint

```bash
npm run lint
```
